Banklytics

Singapore Banking Stock Forecasting

A financial analytics project predicting DBS, OCBC, and UOB stock movement using LSTM models, technical indicators, sentiment analysis, and walk-forward validation.

View Slides View Report

Project Overview

Banklytics explored whether deep learning models could predict short-term movements in Singapore banking stocks using technical and sentiment-based financial indicators.

Key Contributions

Financial Data Collection

Collected OHLCV stock market data for DBS, OCBC, and UOB using yFinance APIs.

Sentiment Analysis

Integrated sentiment signals using GDELT news data and VADER sentiment analysis.

Deep Learning Forecasting

Built stacked LSTM models for next-day log-return prediction on banking stocks.

Time-Series Validation

Applied walk-forward expanding-window validation for realistic sequential forecasting evaluation.

Feature Engineering

Used LASSO and regression-based feature selection to identify significant predictive indicators.
