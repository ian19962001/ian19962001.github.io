PathPal

Assistive Navigation System

A human-centered design project for visually impaired users, using audio and haptic feedback concepts to provide reliable navigation cues.

View Poster Certificate

Project Overview

PathPal explored how wearable navigation support could improve confidence, independence, and safety for visually impaired users.

Key Contributions

User Research

Conducted user research, interviews, and blindfold testing to better understand accessibility challenges.

KPI Definition

Defined KPIs for navigation cue reliability, clarity, comfort, and user confidence.

Feedback System Design

Explored audio and haptic feedback systems for assistive navigation support.

Prototype Development

Contributed to ESP32-CAM wearable prototype concepts for navigation assistance.

Award Recognition

Received the Exemplary Innovation by Design Award for the project.
