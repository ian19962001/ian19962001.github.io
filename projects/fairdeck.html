FairDeck

Responsible AI Bias Awareness System

A design science project that helps ML teams identify fairness risks across the machine learning pipeline using a structured bias-awareness card deck and interactive web application.

View Poster

Project Overview

FairDeck was developed to support cross-functional ML teams in surfacing bias risks before deployment. The project combined Responsible AI research, fairness frameworks, experimental design, and an interactive prototype.

Key Contributions

Bias-Awareness Card Deck

Designed a structured card deck to help ML teams identify fairness risks across the machine learning pipeline.

Interactive Web App

Built an interactive web app to browse and filter cards by pipeline stage and card type.

Controlled Experiments

Conducted controlled experiments using the COMPAS dataset to evaluate the card deck intervention.

Evaluation Metrics

Evaluated bias detection, severity ratings, and pipeline-stage awareness across experiment groups.

Award Recognition

Received the Exemplary Innovation by Design Award for the project.
