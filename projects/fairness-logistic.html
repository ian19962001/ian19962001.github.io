Fairness-Constrained Logistic Regression

Automated Resume Screening using Convex Optimization

A convex optimization project that reformulates automated resume screening as a fairness-aware logistic regression problem using equal opportunity constraints and Lagrangian relaxation.

View Report View Slides

Project Overview

This project explored how automated resume screening systems can inherit and amplify historical hiring bias. We modelled resume screening as a binary classification problem using logistic regression and introduced a fairness-aware objective to reduce group-based disparity.

Key Contributions

Convex Optimization Analysis

Proved that the baseline regularized logistic regression objective is strictly convex using Hessian analysis and L2 regularization.

Fairness Constraint Design

Formulated equal opportunity fairness using group-wise True Positive Rate parity across demographic groups.

Lagrangian Relaxation

Replaced the hard non-convex fairness constraint with a smooth squared penalty optimized using L-BFGS-B.

Fairness-Accuracy Trade-Off

Reduced the TPR gap from 0.257 to 0.032 while limiting the reduction in model accuracy.

Responsible AI Evaluation

Analysed how fairness-aware optimization changes model behaviour and reduces reliance on biased features.
